# Dotfiles for apptainer/singularity.

This folders serves for the apptainer/singularity's configs (e.g., tmux, zshrc). Which need to symlink from singularity's home.

- This [tmux.conf](./tmux.conf) is the copied of [tmux.conf](../tmux-config-sif/tmux.conf).
